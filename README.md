# Faith Demonstration Ministries International: website

Live at https://fdmi-church.vercel.app

Static site, no framework. Pages: Home, About, Leaders, Ministries, Sermons, Events, Announcements, Plan a visit, Gallery.

## Editing
All pages are generated by `build.py`, which holds the shared header, footer,
service times and page content. Edit it, then run:

    python3 build.py

Don't edit the `.html` files by hand: the next build overwrites them.

- `styles.css`: all styling (black, gold and wine, from the church building and crest)
- `script.js`: menu, today's-meeting highlight, days-until-event, calendar file, lightbox
- `assets/photos/`: gallery and section photos
- `assets/video/`: videos
- `assets/og-card.jpg`: the link preview image (1200x630) for WhatsApp, Facebook and X

## To update
- **Service times:** edit `SERVICES` in `build.py` .
- **Next event:** edit `EVENT` in `build.py`.
- **Announcements:** edit `ANNOUNCEMENTS` in `build.py`.
- **Ministries / ministry team:** edit `MINISTRIES` and `TEAM` in `build.py`.
- **Gallery:** add a photo to `assets/photos/` and a line to `GALLERY` in `build.py`.
- **Facebook / YouTube links** currently open a search. Replace them in `footer()` with the church's exact page URLs.

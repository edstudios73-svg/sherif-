# Faith Demonstration Ministries International: website

Live at https://fdmi-church.vercel.app

Static site, no framework. Pages: Home, About, Leaders, Gallery, Events, Visit.

## Editing
All pages are generated by `build.py`, which holds the shared header, footer,
phone tab bar, service times and page content. Edit it, then run:

    python3 build.py

Don't edit the `.html` files by hand: the next build overwrites them.

- `styles.css`: all styling (wine and gold, from the church crest)
- `script.js`: menu, today's-meeting highlight, event countdown, calendar file, gallery lightbox
- `assets/photos/`: gallery and section photos
- `assets/video/`: videos
- `assets/og-card.jpg`: the link preview image (1200x630) for WhatsApp, Facebook and X

## To update
- **Service times:** edit `SERVICES` in `build.py` (and the start times in `footer()`).
- **Next event:** edit `EVENT_CARD` in `build.py` and the dates at the top of the countdown in `script.js`.
- **Gallery:** add a photo to `assets/photos/` and a line to `GALLERY` in `build.py`.
- **Facebook / YouTube links** currently open a search. Replace them in `footer()` with the church's exact page URLs.

# Faith Demonstration Ministries International: website

A one-page static website for FDMI (Adjen-Kotoku, Accra). No build step: open `index.html` or host the folder on any static host (Netlify, Vercel, GitHub Pages).

- `index.html`: page content (event, about, leadership, visit, socials)
- `styles.css`: design (oxblood, wine and gold, taken from the church's flyers)
- `script.js`: mobile menu, countdown to At His Feet, add-to-calendar file
- `assets/`: crest, event flyer and leader portraits
